
EduGenie - AI Personal Tutor

EduGenie is an interactive AI-powered learning support tool designed to help students get instant answers, detailed topic explanations, text summaries, and quizzes using Google Gemini API.

Features:
Ask a Question: Get quick, direct answers to academic queries (e.g., "Why is the sky blue?").  
Need an Explanation?: Step-by-step breakdowns for complex topics (e.g., Photosynthesis).  
Summarize a Paragraph: Shorten long study notes or articles into clear, concise summaries.  
Generate a Quiz: Auto-generate interactive practice quizzes on any topic (e.g., Solar System).  

Tech Stack:
Frontend: HTML, CSS, JavaScript
Backend: Python (FastAPI / Flask)
AI Model: Google Gemini API (gemini-1.5-flash)
